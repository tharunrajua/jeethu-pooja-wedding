MUSIC
No music file was supplied, so this package does not include a soundtrack yet. Modern browsers block audio from autoplaying before a visitor interacts with the page. The best experience is to start music after the visitor taps “Open the Invitation”, with a visible music on/off control. Add your chosen MP3 as music.mp3 and wire it to that first tap once you provide the track.

DEPLOY
Extract the ZIP and replace the corresponding website files in the existing GitHub repository. Keep all image assets in the same folder as index.html, then commit and allow Vercel to redeploy.

NOTE
The website uses the existing Apps Script endpoint for RSVPs and blessings. Test one RSVP and one blessing after deployment to confirm Google Sheets saves them.
