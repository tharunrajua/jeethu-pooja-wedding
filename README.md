# Jeethu & Pooja Wedding Website

## Preview locally
1. Extract this ZIP on Windows.
2. Open the folder and double-click `index.html`.
3. Internet is recommended for web fonts and the Google Maps link. Images and the soft melody are bundled locally.

## Included
- Pastel South Indian-inspired wedding invitation and event cards
- JP floral monogram in the header
- Click-to-play gentle background melody (browsers block autoplay until a guest taps Play)
- RSVP opens a prefilled WhatsApp message to Tharun at 7259547850
- Bangalore hides accommodation fields; Gulbarga and other cities show the number-of-travellers field and accommodation note
- Peacock Grove photo and direct Google Maps link beside RSVP
- Gallery visual preview

## Important
The shared gallery is currently a visual preview; it does not yet upload files or sync photos between guests. WhatsApp RSVP messages are only sent when the guest taps Send.

To publish free, upload `index.html` and the entire `assets` folder to a GitHub repository, then import it into Vercel. Keep the folder structure unchanged.
