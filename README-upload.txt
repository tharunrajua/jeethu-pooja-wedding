Jeethu & Pooja wedding website update

1. Extract this ZIP.
2. Upload the included index.html to the ROOT of your GitHub repository, replacing the existing index.html.
3. Keep your existing image files in the repository root, including couple.png, jp-logo.jpg, haldi.jpg, sangeet.jpg, muhurtham.jpg, peacock-grove.jpg, and gallery1.jpg through gallery4.jpg.
4. Commit the change to the main branch and wait for Vercel to redeploy.
5. Test the live RSVP form with a test response and confirm that a new row appears in the RSVP Responses tab of your Google Sheet.

The index.html contains the Apps Script URL supplied for this deployment. Do not share your spreadsheet edit link publicly. The Apps Script web app is public-facing so anyone with its URL may attempt to submit data; monitor submissions and redeploy/restrict access if needed.

Photo upload button opens the Google Photos link supplied by the organiser. Confirm album permissions allow guests to contribute photos.
